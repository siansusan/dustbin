# Bin Enclosure & Stand — 3D Model

Interactive parametric 3D model of the HDPE bin enclosure and stand.

## How to Open

Double-click **`index.html`** to open it directly in any web browser (Chrome, Edge, Firefox). No installation or build setup required.

You can also view it online via GitHub Pages once enabled in repository settings.

## Controls

- **Rotate**: Left-click + drag
- **Pan**: Right-click + drag
- **Zoom**: Scroll wheel
- **View presets**: Click **Iso**, **Front**, **Side**, or **Top** on the top bar
- **Inside view**: Click **Cutaway** to see inside the enclosure
- **Edit dimensions**: Use the sliders in the left sidebar
- **Export CAD**: Click **Export CAD Model (.scad)** or **Export Params (JSON)**
